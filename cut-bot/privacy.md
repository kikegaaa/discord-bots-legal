# Política de Privacidad — CUTBOT

**Última actualización:** Noviembre de 2026

Esta Política de Privacidad explica cómo **CUTBOT** (en adelante, "el Bot") recopila, utiliza y protege la información cuando interactúas con él en Discord.

## 1. Información que Recopilamos
Para ejecutar sus funciones de creación y subida de emojis y stickers, el Bot procesa únicamente los datos técnicos mínimos necesarios:
* **Identificadores de Discord:** ID de usuario, ID de servidor (Guild ID) e ID de canal para verificar permisos y ejecutar los comandos solicitados.
* **Contenido multimedia temporal:** Imágenes, emojis, stickers, GIFs o fragmentos de video enviados o reenviados explícitamente mediante un comando para su conversión y subida al servidor.

## 2. Uso y Retención de los Datos
* Los archivos multimedia procesados se utilizan **exclusivamente en tiempo real** para generar el emoji o sticker solicitado y subirlo al servidor de Discord correspondiente.
* **No almacenamos** de forma permanente tus imágenes, videos, mensajes privados ni el historial de archivos subidos en bases de datos externas. Una vez procesada la solicitud, los archivos temporales se descartan automáticamente.

## 3. Compartición con Terceros
No vendemos, alquilamos ni compartimos ningún dato de usuarios o servidores con terceros. La información procesada interactúa únicamente con la API oficial de Discord para cumplir la acción solicitada por el usuario.

## 4. Seguridad
Aplicamos medidas técnicas estándar para proteger los tokens y las comunicaciones entre el Bot y los servidores de Discord.

## 5. Derechos del Usuario y Eliminación de Datos
Puedes dejar de compartir datos con el Bot en cualquier momento dejando de utilizar sus comandos o expulsándolo de tu servidor. Para consultas, soporte o solicitudes relacionadas con tus datos y el uso del Bot, puedes abrir un reporte en nuestro repositorio oficial: https://github.com/kikegaaa/discord-bots-legal/issues
